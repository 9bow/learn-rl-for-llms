## 왜 추론을 따로 평가하는가

언어 모델은 유창한 답을 만들면서도 계산·논리·코드의 경계 조건을 틀릴 수 있다. 유창성, 정답률, 생성된 설명의 충실성은 다른 평가 대상이다. 이 장은 추론 학습의 동기를 설명하며 현재 모델 순위를 제시하지 않는다.

## 자기회귀 생성과 중간 계산

자기회귀 모델은 이전 토큰에 조건화하여 다음 토큰을 만든다.

$$P(y\mid x)=\prod_{t=1}^{T}P(y_t\mid x,y_{<t})$$

응답 전체를 한 번의 순전파로 만드는 것은 아니다. 생성 토큰이 늘어나면 다음 단계가 이용할 컨텍스트와 계산도 늘어난다. 따라서 모델에 중간 상태가 구조적으로 전혀 없다는 설명은 부정확하다. 다만 중간 문구가 정확하거나 실제 내부 계산을 충실히 반영한다는 보장은 없다.

## Chain-of-Thought 프롬프팅

[CoT](https://arxiv.org/abs/2201.11903)는 중간 풀이를 예시로 제공하거나 단계적 답변을 유도하는 방법이다. 추론 시 프롬프트를 바꾸며 모델 가중치를 직접 업데이트하지 않는다.

```text
문제: 사탕 18개를 6명이 똑같이 나눈다.
풀이: 18 ÷ 6 = 3
답: 한 명당 3개
```

이는 설명용 예시다. 원 연구의 큰 모델에서 관찰한 효과를 모든 작은 모델에 효과가 없다는 고정 파라미터 임계값으로 일반화하지 않는다. 모델의 훈련 이력·문제·프롬프트에 따라 결과가 달라진다.

## RL 기반 추론 학습

RL은 생성한 풀이·답을 보상으로 평가하고 모델 가중치를 바꾼다. 예를 들어 최종 정답이 맞은 경로를 상대적으로 강화할 수 있다. 학습 중 반성·검증 문구가 늘어도 새로운 능력이 생겼다는 증명은 아니며, 기반 모델과 같은 생성 예산으로 비교해야 한다.

[DeepSeek-R1](https://arxiv.org/abs/2501.12948)은 SFT 없는 R1-Zero 실험과 SFT·RL을 결합한 R1 절차를 구분한다. 공개 가중치와 보고서가 있다고 전체 데이터·계산을 완전히 재현할 수 있다는 뜻은 아니다.

## 학습과 추론 연산을 나누기

| 방법 | 가중치 업데이트 | 추가 연산의 위치 |
|------|-----------------|------------------|
| CoT 프롬프팅 | 없음 | 중간 토큰 생성 |
| RL 후학습 | 있음 | 롤아웃·보상·정책 학습 |
| Best-of-N·검색 | 보통 없음 | 여러 후보·검증·탐색 |
| STaR 자기 학습 | 있음 | 생성·선별·지도 학습 |

이 방법들은 조합할 수 있다. 같은 최종 정확도라도 학습 비용, 매 요청 생성 비용, 지연, 도구 사용량은 다르다.

## System 1·2는 비유다

빠른 직관과 느린 숙고라는 인간 사고의 비유는 연구 동기를 설명하는 데 유용하다. 그러나 모든 언어 모델을 System 1이라고 단정하거나, 긴 CoT를 생성하면 System 2 능력을 획득했다고 판정할 수는 없다.

검증 가능한 문제, 충분한 평가 표본, 보지 않은 유형, 같은 토큰 예산을 사용해 실제 개선을 측정한다. 다음 장은 이런 목표를 critic 없이 학습하는 GRPO를 다룬다.
