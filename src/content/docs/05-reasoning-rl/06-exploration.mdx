## 탐색과 보상 희소성

한 프롬프트의 응답이 모두 오답이면, 그룹 평균을 뺀 정확성 advantage는 모두 0이다. 같은 오류를 반복하는 모델에는 새로운 풀이를 발견할 탐색이 필요하다. 그러나 새로운 출력이라는 이유만으로 보상을 주면 의미 없는 응답도 강화할 수 있다.

내재적 보상은 정답 여부 외에 새로움이나 불확실성을 학습 신호로 사용한다. 외재적 정답 보상과 내재적 보상을 분리해 기록하고, 실제 정확도·생성 길이·응답 다양성을 함께 평가한다.

## IMAGINE: 궤적을 고려한 탐색

[IMAGINE](https://arxiv.org/abs/2505.17621)은 궤적 수준 탐색 보상, 오답 조건부 보상 배분, 기존 advantage를 보존하는 통합을 연구한다. 개별 토큰의 낯섦만 보상하면 생기는 편향과 어려운 문제의 희소 신호를 다룬다.

이는 모든 오답에 새로움 보너스를 주는 규칙과 다르다. 논문의 구성 요소를 재현하려면 보상 배분과 advantage 통합도 구현해야 한다. 벤치마크 개선을 다른 모델·검증기에서 보장하는 방법으로 해석하지 않는다.

## MERCI: 의사 방문 횟수

[Count Counts](https://arxiv.org/abs/2510.16614)의 MERCI는 `Motivating Exploration in LLM Reasoning with Count-based Intrinsic Rewards`를 뜻한다. Coin Flipping Network로 궤적의 의사 방문 횟수와 인식적 불확실성을 추정한다. 모든 응답 문자열의 실제 방문 횟수를 사전에 저장하는 방식이 아니다.

카운트 기반 보상의 기본 직관은 아래 교육용 식으로 볼 수 있다. 이 식은 MERCI 전체 목적식을 대신하지 않는다.

$$r_{\text{novelty}}(z)=\frac{1}{\sqrt{N(z)+1}}$$

낯선 궤적 표현 $z$에는 더 큰 보너스를 준다. 무엇을 같은 궤적으로 묶는지에 따라 결과가 달라진다. 문자열만 바꿔 같은 잘못된 풀이를 반복하는 경우를 구별해야 한다.

## 엔트로피와 온도

정책 엔트로피 보너스는 분포가 너무 일찍 좁아지는 것을 억제한다. 샘플링 온도는 실제 롤아웃 분포를 바꾼다. 두 방법은 서로 다른 위치에 작동하므로 같은 장치로 취급하지 않는다.

DAPO의 동적 샘플링은 동점 그룹을 다른 프롬프트로 교체한다. 온도를 자동 조절하는 알고리즘은 아니다. 보상 다양성이 없는 그룹의 비율과 재샘플링 비용을 별도로 기록한다.

## 비교 실험

| 장치 | 바꾸는 대상 | 함께 측정할 항목 |
|------|-------------|----------------|
| 온도 | 롤아웃 토큰 분포 | 정확도, 엔트로피, 길이 |
| 엔트로피 보너스 | 학습 목적식 | 정답 보상과 보너스의 크기 |
| 내재적 보상 | 궤적의 학습 가중치 | 새로움과 실제 성공의 관계 |
| 동적 샘플링 | 유효 프롬프트 구성 | 동점 그룹 비율, 생성 비용 |

같은 문제와 생성 토큰 예산에서 비교한다. 추론 문구가 다양해졌다는 관찰과 새로운 정답 풀이를 찾았다는 결과를 구분한다.
