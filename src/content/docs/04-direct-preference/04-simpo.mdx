## DPO 암묵적 보상과의 수학적 비교

DPO의 암묵적 보상은 [학습 정책과 참조 정책](../../01-rl-fundamentals/00-notation/#policies) 사이의 정책 비율(log-ratio)로 정의된다.

$$
r_{\text{DPO}}(x, y) = \beta \log \frac{\pi_\theta(y \mid x)}{\pi_{\text{ref}}(y \mid x)}
$$

> **직관.** [\\(\beta\\)](../../01-rl-fundamentals/00-notation/#dpo)는 로그 비율의 스케일을 결정한다 — 작으면 보상을 공격적으로 추구하고, 크면 참조에 묶인다. 이 보상은 참조 모델이 반드시 필요하다는 의미를 담고 있어, 학습 시 메모리 비용의 역할을 만든다. 왜 비율인가 — 분배 함수가 상쇄되도록 설계된 DPO 유도에서 비롯된 결정이다.

이 보상은 두 가지 문제를 내포한다. 첫째, 참조 모델 $\pi_{\text{ref}}$가 반드시 필요하므로 학습 시 두 모델을 동시에 메모리에 올려야 한다. 둘째, $\log \pi_\theta(y|x) = \sum_{t=1}^{|y|} \log \pi_\theta(y_t|x, y_{<t})$는 토큰 수에 비례하는 합산값이므로, 길이가 다른 응답 간 직접 비교가 불공평하다.

SimPO는 참조 모델 의존성을 제거하고 길이를 명시적으로 정규화함으로써 두 문제를 모두 해결한다.

## SimPO의 핵심 아이디어

**SimPO(Simple Preference Optimization)** 는 Princeton NLP 그룹이 2024년 제안한 방법으로, DPO보다 단순하면서 더 강력한 성능을 보입니다. 핵심 아이디어는 두 가지다.

첫째, 참조 모델(reference model)을 완전히 제거합니다. DPO는 정책 비율 $\frac{\pi_\theta(y|x)}{\pi_{\text{ref}}(y|x)}$를 암묵적 보상으로 사용하지만, SimPO는 **평균 로그 확률** 을 직접 암묵적 보상으로 사용합니다.

$$
r_{\text{SimPO}}(x, y) = \frac{1}{|y|} \log \pi_\theta(y \mid x) = \frac{1}{|y|} \sum_{t=1}^{|y|} \log \pi_\theta(y_t \mid x, y_{<t})
$$

> **직관.** 길이로 정규화한 평균 로그 확률을 보상으로 쓴다. 길이에 따라 보상이 왜곡되는 편향을 제거하며, 참조 모델 없이도 학습 가능하다는 의미다. 합 로그 확률은 토큰 수에 의존해 길이에 따라 체계적으로 커지거나 줄어드는데, 평균으로 바꾸면 단위 토큰당 "확신"을 비교하는 양으로 해석이 바뀌는 역할을 한다.

둘째, 응답 길이 $|y|$로 나누어 **길이 정규화** 를 수행합니다. 이는 시퀀스 합 로그 확률이 길이의 영향을 받는 문제(length bias)을 방지합니다.

## SimPO 손실 함수

SimPO는 BT 모델 구조를 유지하면서 마진 항 $\gamma$를 추가합니다.

$$
L_{\text{SimPO}}(\pi_\theta) = -\mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}}\!\left[\log \sigma\!\left(\frac{\beta}{|y_w|}\log \pi_\theta(y_w|x) - \frac{\beta}{|y_l|}\log \pi_\theta(y_l|x) - \gamma\right)\right]
$$

> **직관.** 선호-비선호 사이에 최소 격차 $\gamma$를 강제해 선호 신호가 확실히 반영되도록 한다. DPO처럼 부호만 맞추는 데 그치지 않고 "얼마나 더 나아야 하는가"를 결정하는 역할을 한다. [\\(\beta\\)](../../01-rl-fundamentals/00-notation/#dpo)는 로짓의 전체 스케일을, $\gamma$는 결정 경계 너머의 여유 폭을 조절한다는 의미다.

여기서 $\gamma > 0$는 **목표 보상 마진** 으로, 선호 응답과 비선호 응답 사이에 최소 마진을 강제합니다. 이는 DPO에 없는 요소로, 경계 사례에서 더 명확한 분리를 유도합니다. 하이퍼파라미터는 모델·데이터별 실험 설정을 따른다. 단일 β·γ 조합을 보편적 권장 기본값으로 해석하지 않는다.

## 보상 마진 γ의 역할

DPO의 logistic 손실은 유한한 마진에서 0이 되지 않는다. 마진이 0이면 손실은 $\log 2$이고, 양의 무한대로 갈 때 0에 접근한다. SimPO는 목표 마진 γ로 logistic 결정 경계를 이동시킨다. 이는 경계 사례(margin이 거의 없는 경우)에서 분류 경계가 불분명해지는 문제를 유발한다.

SimPO의 $\gamma > 0$는 선호 응답의 스케일된 평균 로그 확률 차이가 γ를 넘으면 손실이 $\log 2$보다 작아진다. γ 아래에서도 마진이 증가하면 손실은 줄어든다.

$$
\frac{\beta}{|y_w|}\log \pi_\theta(y_w|x) - \frac{\beta}{|y_l|}\log \pi_\theta(y_l|x) > \gamma
$$

> **직관.** 이 부등식이 언제 성립하지 않는지가 학습 신호의 역할을 결정한다. 마진이 γ와 같으면 손실은 $\log 2$다. 이 경계는 하드 제약이 아니며, 유한한 마진에서 그래디언트는 여전히 존재한다. 즉 $\gamma$는 "충분한 분리"의 정의를 바꾼다.

이 마진은 두 가지 효과를 가진다. 첫째, 경계 사례에서 더 명확한 결정 경계를 학습하게 하여 일반화 성능을 향상시킨다. 둘째, 모델이 단순히 선호/비선호 방향만 맞추는 게 아니라 일정 수준 이상의 분리를 달성하도록 유도하여 응답 품질 격차를 키운다. 마진의 이점은 논문의 절제 실험에서 평가한다. 특정 값이 다른 기반 모델에서도 최적이라고 가정하지 않는다.

## 참조 모델 제거의 실용적 이점

참조 모델을 제거함으로써 얻는 실용적 이점은 상당하다.

| 항목 | DPO | SimPO |
|------|-----|-------|
| 학습 시 GPU 메모리 | 정책 + 참조 모델 | 정책 모델만 |
| 배치당 순전파 횟수 | 2회 (정책 + 참조) | 1회 |
| 구현 복잡도 | 참조 모델 관리 필요 | 단순 |
| 추론 시 추가 비용 | 없음 | 없음 |

참조 추론 비용을 줄일 수 있지만 전체 GPU 메모리가 절반이 된다는 뜻은 아니다. 정책의 옵티마이저·그래디언트·활성화와 참조 로그 확률 사전 계산 여부도 비용에 영향을 준다.

## 원 논문의 성능 평가

SimPO 논문은 여러 기반 모델과 설정에서 AlpacaEval 2·Arena-Hard·MT-Bench를 비교한다. 기반 모델 자체의 점수와 DPO 후학습 점수, 길이 제어 승률과 원 승률을 구분해야 한다. 논문의 특정 조건에서 관찰한 개선을 모든 모델 크기의 공통 우위로 해석하지 않는다.

## DPO vs SimPO vs ORPO 비교

| 항목 | DPO | SimPO | ORPO |
|------|-----|-------|------|
| 참조 모델 필요 | 예 | **아니오** | 아니오 |
| 보상 마진 강제 | 아니오 | **예 (γ)** | 아니오 |
| 길이 정규화 | 원 목적식은 합 로그 확률 | **평균 로그 확률** | **평균 로그 확률** |
| GPU 메모리 | 정책 + 참조 | **정책만** | 정책만 |
| 손실 구조 | 독립적 분류 | 독립적 분류 | SFT + 선호 결합 |
| 하이퍼파라미터 | β | β, γ | λ |

ORPO는 SFT 손실과 오즈 비 선호 손실을 결합합니다. SimPO는 준비된 초기 정책에 평균 로그 확률 보상과 목표 마진을 적용합니다. 명시적 마진의 유무만으로 경계 사례의 품질이나 두 방법의 우열을 판단할 수 없습니다.

## 길이 정규화의 중요성

길이 정규화 없이 단순히 $\log \pi_\theta(y|x)$를 보상으로 사용하면, 합 로그 확률은 토큰을 더할수록 작아지므로, 원시 가능도 비교는 짧은 응답을 선호할 수 있습니다. 자동 회귀 언어 모델의 확률은 토큰이 추가될수록 감소하는 경향이 있어, 짧은 응답이 수학적으로 더 높은 확률을 가질 수 있습니다. 길이 정규화는 합 로그 확률의 직접적인 길이 의존성을 완화하지만, 보상이나 데이터에 남은 길이 편향까지 자동으로 제거하지는 않습니다.

## 정리

SimPO는 "단순할수록 좋다"는 원칙의 좋은 예다. 참조 모델을 제거하고 평균 로그 확률과 마진을 더하는 최소한의 변경만으로 DPO를 능가하는 성능을 달성했다. 이는 해당 실험에서 참조 모델 없는 선호 최적화가 경쟁력 있음을 보여줍니다. ORPO는 SimPO보다 먼저 발표된 별도 접근이며, 온라인 RL인 DAPO와도 학습 데이터·목적식이 다릅니다.
