## 피드백 제공자와 생성 모델

AI 피드백은 모델이 응답의 품질을 평가해 학습 신호를 제공하는 방법이다. 이미지를 잘못 읽는 평가자는 같은 환각을 정책에 전파할 수 있다. 평가 능력과 답 생성 능력은 별도로 측정해야 한다.

## RLAIF-V

[RLAIF-V](https://arxiv.org/abs/2405.17220)는 공개 멀티모달 모델을 이용한 세밀한 피드백 생성과, 추론 시 자기 피드백을 연구한다. 응답의 세부 주장에 대한 확인을 나누어 피드백 품질을 높인다.

공개 모델만 쓰는 피드백 파이프라인은 비용과 재현성에 도움이 될 수 있다. 다만 학습 자료·모델 라이선스·평가 판정자까지 모두 같은 공개성 조건을 갖는다고 가정하지 않는다. 논문 제목의 GPT-4V 비교는 지정된 신뢰성 평가의 결과이며 모든 VQA·추론 과제의 우위를 뜻하지 않는다.

## LLaVA-Critic

[LLaVA-Critic](https://arxiv.org/abs/2410.02712)은 다양한 시각 태스크의 평가 지시 데이터로 학습한 범용 평가자다. 단일 응답의 점수와 두 응답의 상대 비교를 다룬다. 생성한 선호 신호를 정책 개선에 활용하는 실험도 포함한다.

평가자 실험에서는 인간 선호와의 일치, 점수 상관, 쌍 비교 판정 등을 본다. MathVista·MMMU 등의 문제에 직접 답하는 생성 정확도와 같은 지표가 아니다. 모델이 다른 응답을 잘 평가했다고 그 문제의 최고 생성 모델이라고 결론 내릴 수 없다.

## LLaVA-Critic-R1

[LLaVA-Critic-R1](https://arxiv.org/abs/2509.00676)은 선호 레이블이 있는 비평 자료를 검증 가능한 학습 신호로 재구성하고, 생성 가능한 기반 모델에 RL을 적용한다. 선호 판정 학습 후에도 답 생성 능력이 유지·향상되는지를 연구한다.

이를 비평 손실과 생성 손실을 단순 합산한 임의의 다중 과제 목적식으로 대체하지 않는다. 논문은 평가자 품질, 직접 생성, 추론 시 자기 비평을 나누어 평가한다. 이 결과는 모든 critic을 곧바로 좋은 정책으로 사용할 수 있다는 보장이 아니다.

## 평가 설계

| 평가 대상 | 지표 예시 | 주의할 점 |
|-----------|-----------|-----------|
| 선호 판정 | 인간 비교와 일치율 | 응답 순서를 바꾸어 위치 편향 검사 |
| 사실성 | 객체·관계 환각 비율 | 이미지가 없을 때의 언어 편향 |
| 직접 생성 | VQA·추론 정답률 | critic 점수와 구분 |
| 자기 비평 | 같은 토큰 예산의 성공률 | 반복 생성 비용도 포함 |

동일 계열 모델로 생성·평가를 모두 수행하면 공유된 오류가 가려질 수 있다. 독립 검증과 일부 인간 평가를 두고, 판정자·프롬프트·모델 버전을 기록한다.
