## 시각적 추론의 여러 표현

시각적 추론은 이미지의 관계·수량·공간 상태를 이용해 답이나 행동을 만드는 과정이다. 추론을 텍스트로 표현하는 방법, 잠재 상태로 표현하는 방법, 미래 이미지를 목표로 생성하는 방법은 서로 다르다.

## Latent Chain-of-Thought

[Latent Chain-of-Thought for Visual Reasoning](https://arxiv.org/abs/2510.23925)은 추론 경로를 잠재 변수로 두고 사후분포 추론(posterior inference)으로 정식화한다. 여기서 posterior는 관측된 자료에 조건화한 확률분포다. 답을 먼저 만든 뒤 설명을 붙이는 사후 설명(post-hoc explanation)과 다르다.

논문은 상각 변분 추론, 다양한 잠재 CoT를 찾는 RL, 주변 가능도를 사용하는 추론 시 선택을 연구한다. 단순히 형식 보상을 더하는 GRPO 레시피로 요약할 수 없다.

## CoT-VLA: 미래 이미지를 목표로

[CoT-VLA](https://arxiv.org/abs/2503.22020)는 현재 관측과 지시에서 미래 프레임을 생성하고, 그 시각 목표에 도달하는 짧은 행동 시퀀스를 생성한다. 미래 이미지가 중간 계획을 표현한다.

```text
현재 관측 + 지시 → 미래 목표 이미지 → 짧은 행동 시퀀스
실행 후 관측 → 다음 목표 이미지 → 다음 행동
```

이는 로봇 행동의 시각적 계획을 설명하는 사례다. CoT를 사용했다는 사실만으로 RL 학습 방법이라고 분류하지 않는다. 실세계·시뮬레이션 실험의 기준 모델과 평가 조건을 따로 읽는다.

## VL-DAC: 환경 단계의 가치 추정

[VL-DAC](https://arxiv.org/abs/2508.04280)는 Vision-Language Decoupled Actor-Critic을 뜻한다. PPO 정책 업데이트는 행동 토큰에 적용하고, 가치 추정은 환경 단계 수준에서 학습한다. 자율 커리큘럼의 약자가 아니다.

논문은 MiniWorld·Gym-Cards·ALFWorld·WebShop 중 하나의 저비용 환경에서 훈련한 정책의 전이를 평가한다. BALROG의 상대 개선율을 임의의 절대 점수표로 바꾸면 안 된다. 논문이 hyperparameter-free라고 설명하는 범위도 알고리즘의 가중치 설계이며, 학습률·모델·환경 구성이 사라진다는 뜻은 아니다.

## Latent Visual Reasoning

[Latent Visual Reasoning](https://arxiv.org/abs/2509.24251)은 중요한 시각 토큰을 복원하는 잠재 상태를 생성하고, 이를 텍스트 생성과 섞는다. 언어 모델이 전혀 관여하지 않는 순수 이미지 연산은 아니다. 논문은 잠재 추론과 텍스트 생성을 조정하는 GRPO 변형도 연구한다.

## 공정한 비교

| 방법 | 추론·학습 단위 | 구분할 점 |
|------|---------------|-----------|
| Latent CoT | 잠재 추론 경로 | 사후분포와 사후 설명 |
| CoT-VLA | 미래 프레임과 행동 | 시각 계획과 RL 여부 |
| VL-DAC | 행동 토큰과 환경 가치 | 토큰 단계와 환경 단계 |
| LVR | 잠재 시각 토큰과 텍스트 | 시각 표현과 언어 생성의 결합 |

같은 VQA 점수와 로봇 성공률을 한 순위표에 합치지 않는다. 관측 해상도, 행동 예산, 검증기, 학습·평가 환경 차이를 기록한다.
