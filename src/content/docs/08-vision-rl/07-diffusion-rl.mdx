## 디노이징을 정책으로 보기

확산 모델의 생성 과정은 노이즈에서 샘플을 점차 복원한다. RL은 최종 샘플의 비미분 보상도 최적화할 수 있다. 다만 선호 정렬에 반드시 RL만 필요한 것은 아니며, 지도 미세조정·선호 최적화와 비교해야 한다.

DDPO의 정식화에서는 현재 노이즈 상태와 조건이 상태이고, 다음 디노이징 샘플이 행동이다. 신경망의 노이즈 예측은 그 전이 분포를 매개변수화한다. 상태와 행동을 네트워크 출력 자체와 혼동하지 않는다.

$$\pi_\theta(x_{t-1}\mid x_t,c)$$

조건 $c$는 프롬프트 등이다. 실제 확률 밀도를 계산하려면 논문이 사용하는 확률적 샘플러와 분산 설정도 정해야 한다.

## DDPO

[Training Diffusion Models with Reinforcement Learning](https://arxiv.org/abs/2305.13301)은 디노이징 과정을 다단계 의사결정으로 두고 정책 경사를 적용한다. 압축률·미적 품질·프롬프트 정렬 같은 최종 목표를 연구한다.

중요도 샘플링 변형은 이전 정책의 로그 확률을 보존해 표본을 재사용한다. 이는 오래된 표본을 제한 없이 재사용한다는 뜻이 아니다. 샘플러·클리핑·롤아웃 정책을 함께 고정한다. 여기서 DDPO는 이미지 생성 알고리즘이며 RLHF-V의 dense DPO와 다르다.

## DPOK

[DPOK](https://arxiv.org/abs/2305.16381)는 학습된 피드백 보상을 최대화하면서 사전학습 확산 모델과의 KL 정규화를 연구한다. 프롬프트 정렬과 이미지 품질을 평가한다.

KL 항은 기반 분포와의 이탈을 줄일 수 있지만 모든 형태의 다양성 붕괴를 막는 보장은 아니다. 별도의 이미지 다양성 평가와 독립 선호 평가가 필요하다.

## DPPO는 로봇 제어 정책이다

[Diffusion Policy Policy Optimization](https://arxiv.org/abs/2409.00588)은 연속 제어·로봇 학습을 위한 확산 정책의 RL 미세조정을 다룬다. 상위 시간축은 환경의 행동·상태 전이이고, 내부 시간축은 행동을 생성하는 디노이징 과정이다.

이는 텍스트 프롬프트로 이미지 계획을 선택하는 상위 MDP가 아니다. 같은 확산 매개변수화를 사용해도 이미지 생성 보상과 로봇 환경 수익은 다른 목표다. 로봇 성공률과 CLIP 점수를 한 성능표에서 비교하지 않는다.

## DRIFT와 다양성

[Beyond the Dirac Delta](https://arxiv.org/abs/2601.12401)는 DRIFT를 제안한다. 보상 이상값을 거르는 표본 선택, 확률적 프롬프트 변형, 그룹 내 다양성을 장려하는 potential 기반 보상 shaping을 결합한다.

이 방법을 단순한 엔트로피 항 추가로 요약하면 실제 기여를 놓친다. 보상 정렬과 출력 다양성의 관계를 같은 조건에서 비교해야 한다. 임의의 CLIP 분산 손실을 다른 논문의 검증된 알고리즘으로 소개하지 않는다.

## 비교의 기준

| 방법 | 적용 대상 | 핵심 확인 |
|------|-----------|-----------|
| DDPO | 생성 샘플의 최종 보상 | 디노이징 로그 확률·샘플러 |
| DPOK | 피드백 정렬 이미지 생성 | 참조 분포·KL·보상 모델 |
| DPPO | 연속 제어·로봇 정책 | 환경 단계와 디노이징 단계 |
| DRIFT | 다양성을 보존하는 생성 정렬 | 표본·프롬프트·그룹 shaping |

보상 점수만으로 품질을 판단하지 않는다. 보지 않은 프롬프트, 인간 선호, 다양성, 실패 사례, 전체 생성 비용을 함께 보고한다.
