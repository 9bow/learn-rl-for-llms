## 무엇을 순수 RL이라고 부르는가

추가 후학습 단계를 RL만으로 수행했다는 설명과, 모델의 전체 학습 이력에 SFT·증류가 없었다는 주장은 다르다. 정답 보상이 규칙 기반인지 학습된 검증기인지도 따로 구분해야 한다.

수치 정답은 답 파싱·단위·정의역을 정한 후 비교할 수 있다. 자연어 수학 증명은 같은 방식으로 자동 검증되지 않는다.

## AceMath-RL-Nemotron-7B

[NVIDIA 모델 카드](https://huggingface.co/nvidia/AceMath-RL-Nemotron-7B)는 시작점을 `DeepSeek-R1-Distill-Qwen-7B`로 명시한다. 이 체크포인트는 이미 증류 SFT를 거친 모델이다. 이후 수학 RL을 수행했다는 사실을 "사전학습부터 SFT 없이 학습"으로 바꾸어 설명하면 안 된다.

모델 카드가 같은 평가 설정에서 보고한 값은 다음과 같다.

| 모델 | AIME 2024 AVG@64 | AIME 2025 AVG@64 | LiveCodeBench AVG@8 |
|------|-----------------|-----------------|--------------------|
| DeepSeek-R1-Distill-Qwen-7B | 55.5 | 39.2 | 37.6 |
| AceMath-RL-Nemotron-7B | 69.0 | 53.6 | 44.4 |

`AVG@64`는 여러 생성의 평균 정답률 추정이다. 64개 중 하나만 맞아도 성공하는 `pass@64`나 다수결 점수와 다르다. LiveCodeBench 결과도 모델 카드의 문제 기간·생성 조건을 함께 기록해야 한다.

수학 중심 추가 RL 후 코딩 평가도 향상된 사례지만, 모든 도메인으로의 전이나 "작은 모델이 항상 큰 모델을 이긴다"는 법칙은 아니다. 현재의 최상위 모델 순위를 나타내는 표도 아니다.

## DeepSeekMath-V2: 자연어 증명 검증

[DeepSeekMath-V2](https://arxiv.org/abs/2511.22570)는 자연어 증명을 평가하는 LLM 검증기를 학습하고, 생성기가 자기 증명을 검토·개선하도록 학습한다. 검증기가 다른 강한 검증기나 메타 검증으로 개선되는 절차도 연구한다.

이 검증은 Lean 같은 형식 증명 커널이 정리를 확인하는 방식과 다르다. 자연어 검증기는 오류를 낼 수 있으며, 형식 증명 보장으로 설명할 수 없다.

논문은 확장된 테스트 타임 연산에서 IMO 2025 금메달 기준의 성적과 Putnam 2024 118/120점을 보고한다. 실제 대회에서 메달을 받은 기록이 아니다. 생성·검증 연산과 채점 조건을 인간 참가자의 시간 제한과 구분한다.

## 두 사례에서 배울 점

| 구분 | AceMath-RL | DeepSeekMath-V2 |
|------|------------|----------------|
| 핵심 대상 | 정답이 있는 수학 문제 | 자연어 증명과 자기 검증 |
| 시작점 해석 | 증류된 7B 모델의 추가 RL | 논문에 제시된 생성·검증 학습 절차 |
| 결과 해석 | 지정 벤치마크의 평균 정답률 | 지정 연산 예산의 증명 채점 결과 |
| 주의점 | 전체 이력을 SFT 없는 훈련으로 오인 | LLM 검증을 형식 증명으로 오인 |

보상 출처, 초기 체크포인트, 훈련 데이터, 평가 연산을 분리해 기록해야 서로 다른 연구를 공정하게 비교할 수 있다.
