## 여러 턴을 하나의 목표로 보기

멀티턴 RL은 개별 답뿐 아니라 후속 사용자·환경 반응을 포함한 상호작용의 결과를 최적화한다. 지금 질문을 되묻거나 정보를 모으는 행동이 나중의 성공에 도움이 될 수 있다.

턴 $t$의 상태는 현재 사용자 입력까지의 이력이며, 행동 $a_t$는 에이전트 응답이다. 그 뒤 환경이나 사용자 반응 $u_{t+1}$을 받아 다음 상태를 만든다.

$$s_{t+1}=(s_t,a_t,u_{t+1})$$

사용자의 숨은 목표를 모두 볼 수 없으면 부분 관측 문제가 된다. 모든 대화 이력을 기록해도 숨은 상태를 직접 관측하는 것과 같지는 않다.

## 신용 할당과 마스크

최종 성공만 보상하면 어느 턴이 기여했는지 알기 어렵다. 가치 함수·장기 수익·단계별 검증을 사용할 수 있지만, 중간 점수가 최종 목표와 맞는지 확인해야 한다.

훈련 손실은 모델이 생성한 응답·도구 호출 토큰에 적용한다. 사용자 메시지·도구 실행 결과는 환경 관측이므로 그대로 정책 행동으로 학습하지 않는다. 롤아웃 정책의 로그 확률과 버전도 보존한다.

## LMRL Gym의 실제 여덟 과제

[LMRL Gym](https://arxiv.org/abs/2311.18232)은 온라인 시뮬레이터와 오프라인 데이터를 제공한다. 원 논문의 과제는 다음과 같다.

| 범주 | 과제 |
|------|------|
| 탐색 | Maze, Text-Nav |
| 게임 | Wordle, Chess, Chess Endgames |
| 대화 | Twenty Questions, Guess My City, Car Dealer |

Persuasion·Diplomacy·Prisoner's Dilemma는 이 여덟 과제 목록에 없다. 논문은 온라인 PPO와 오프라인 가치·정책 방법을 비교하며, 과제별 승자가 다르다. 모든 과제를 하나의 임의 평균 승률로 합치면 이 차이를 잃는다.

## REFUEL: 이후 대화의 가치 학습

[REFUEL](https://arxiv.org/abs/2410.04612)은 `Regressing the Relative Future`를 뜻한다. 고정 데이터의 이전 턴이 참조 정책에서 왔을 때 생기는 분포 불일치를 다룬다.

스스로 생성한 대화 데이터를 반복 수집하고, 하나의 모델로 Q값을 추정하는 회귀 문제로 학습한다. 이를 단순한 턴별 DPO 손실이나 페르소나 일관성 보상으로 바꾸어 설명할 수 없다. 실험에는 Llama-3.1-70B-it 사용자 시뮬레이터가 포함되므로 실제 사람과의 결과로 일반화하지 않는다.

## 상태 압축과 일관성

긴 이력을 요약하면 컨텍스트 비용을 줄일 수 있다. 그러나 요약이 필요한 정보를 지우면 상태 추정이 나빠진다. 고정 길이 요약을 사용한다고 대화 전체 계산이 자동으로 $O(1)$이 되지는 않는다.

페르소나나 제약의 일관성은 별도 평가 항목으로 둘 수 있다. 이는 교육용 설계 선택이며, 특정 논문이 불일치를 일정 비율 줄였다는 근거 없는 성능 주장과 구분한다. 사용자의 정정처럼 이전 답을 수정해야 하는 경우도 있으므로 무조건 같은 답을 고집하도록 보상하지 않는다.

## 평가에서 기록할 항목

성공률 외에 턴 수, 도구 비용, 복구율, 중도 종료, 정책 최신성 저하를 기록한다. 학습과 평가의 사용자 시뮬레이터를 구분하고, 실패한 대화도 평가 분모에 포함한다. 컨텍스트 길이 제한과 절단 방식도 같은 조건으로 유지한다.
