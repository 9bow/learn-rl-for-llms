## 여러 정책과 공동 결과

멀티 에이전트 RL에서는 각 정책의 행동이 다른 정책의 관측·보상에 영향을 준다. 다른 에이전트도 학습하면 한 정책에서 본 환경은 계속 달라질 수 있다. 이를 비정상성 문제라고 한다.

협력 과제는 팀 보상을 공유하고, 경쟁 과제는 에이전트별 보상이 다를 수 있다. 여러 에이전트를 단순히 호출하는 것과 그 정책들을 공동 보상으로 학습하는 것을 구분한다.

## 중앙화 훈련과 분산 실행

CTDE는 훈련할 때 공동 정보를 사용하되, 실행 정책은 각자 허용된 관측으로 행동하는 설계다. 중앙 critic은 기여도 추정에 도움을 줄 수 있지만 정확한 기여를 보장하지 않는다.

공동 보상을 에이전트별로 나누는 방법에는 여러 선택이 있다. Shapley 값도 일반적인 분석 도구지만, 특정 논문이 사용했다고 주장하려면 실제 목적식과 구현 근거가 필요하다.

## MARFT

[MARFT](https://arxiv.org/abs/2504.16129)는 LLM의 역할 의존성과 자기회귀 출력을 고려한 Flexible Markov Game을 정식화한다. 선행 에이전트에 조건화한 정책 최적화, 중앙 critic, 어댑터, 토큰 수준 신용 할당을 다룬다.

현재 공개 초록은 고정된 2~4 에이전트 수학·코딩 워크플로우에서 공유·비공유 정책과 IPPO를 비교한다고 설명한다. 임의의 다섯 역할 소프트웨어 팀에서 완성도가 37.2% 향상되었다는 사례로 바꾸어 제시하지 않는다. 지정된 역할과 동적으로 생겨난 역할도 구분한다.

## MAGRPO

[LLM Collaboration With Multi-Agent Reinforcement Learning](https://arxiv.org/abs/2508.04652)은 협업을 협력 MARL 문제로 두고 Multi-Agent Group Relative Policy Optimization(MAGRPO)을 제안한다. 글쓰기·코딩 협업을 평가한다.

이 연구를 경쟁·사회적 딜레마 전반의 보편 법칙으로 확장하지 않는다. 역할 특화가 자동으로 발생하거나 에이전트 수가 늘수록 성능이 좋아진다는 보장은 없다.

## 사회적 딜레마의 예시

죄수의 딜레마는 개별 유인과 공동 이익의 차이를 보여 주는 교육용 게임이다.

|  | 상대 협력 | 상대 배반 |
|--|-----------|-----------|
| 협력 | (3, 3) | (0, 5) |
| 배반 | (5, 0) | (1, 1) |

반복 조건과 상대 전략에 따라 결과가 달라진다. 위 표만으로 LLM이 특정 협력 전략을 자연스럽게 학습한다고 주장할 수 없다. 기존 비언어 MARL 결과와 LLM 실험도 구분한다.

## 통신과 평가

에이전트 메시지는 다른 정책의 입력이 될 수 있다. 읽을 수 있는 자연어 메시지도 거짓·오류·누락을 포함할 수 있으므로 최종 실행 결과와 대조한다.

| 비교 항목 | 고정할 조건 |
|-----------|-------------|
| 단일 대 다중 정책 | 총 생성 토큰·도구 호출·시간 |
| 역할 분담 | 동일·공유·역할별 파라미터 |
| 보상 | 팀 결과와 개별 기여 지표 |
| 환경 | 통신 경로·관측·실행 권한 |

완전 연결 통신의 메시지 쌍 수는 에이전트 수의 제곱에 비례할 수 있다. 그러나 창발 복잡도나 총 조율 비용에 보편적인 제곱·로그 법칙이 있는 것은 아니다. 실제 시스템에서 성공률·조율 비용·실패 원인을 함께 측정한다.
