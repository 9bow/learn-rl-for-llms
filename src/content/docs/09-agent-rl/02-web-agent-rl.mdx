## 웹과 디바이스의 환경

웹 에이전트는 클릭·입력·탐색을 통해 목표를 수행한다. 화면이나 DOM은 부분 관측이며, 작업 결과는 서버 데이터·파일·계정 상태로 확인해야 한다. 실제 환경의 변경 가능성과 학습용 복제 환경을 구분한다.

## WebRL

[WebRL](https://arxiv.org/abs/2411.02337)은 실패한 시도에서 새 과제를 생성하는 자기 진화 커리큘럼, 결과 감독 보상 모델(ORM), 온라인 분포 이동을 다루는 학습 전략을 결합한다.

원 논문은 WebArena 전체가 아니라 WebArena-Lite에서 Llama-3.1-8B의 성공률 4.8%→42.4%를 보고한다. 이 결과는 특정 환경·행동 예산·보상 모델의 실험이다. 모델 크기만으로 설명하거나 모든 실제 웹 작업에 일반화하지 않는다.

ORM은 결과를 감독하는 모델이다. 이를 임의의 토큰별·중간 단계 보상식으로 바꾸어 설명하면 원 논문의 구성을 잃는다.

## WebAgent-R1

[WebAgent-R1](https://arxiv.org/abs/2505.16421)은 온라인 웹 상호작용에서 멀티턴 궤적을 생성하고, 작업 성공 여부의 이진 보상으로 학습한다. 비동기 궤적 생성과 초기 behavior cloning의 영향을 연구한다.

WebArena-Lite에서 Qwen-2.5-3B 6.1%→33.9%, Llama-3.1-8B 8.5%→44.8%를 보고한다. WebRL의 표와 다른 초기화·학습 조건이 있을 수 있으므로 향상 배수만으로 방법의 우열을 정하지 않는다.

비동기화는 여러 독립 환경의 대기 시간을 겹치는 방식이다. 하나의 궤적에서 아직 도착하지 않은 관측을 미리 사용해 다음 행동을 결정할 수 있다는 뜻은 아니다.

## DigiRL

[DigiRL](https://arxiv.org/abs/2406.11896)은 Android 환경에서 사전학습된 1.3B VLM을 먼저 오프라인 RL로 초기화하고, 오프라인→온라인 학습으로 개선한다. 환경에는 VLM 기반 평가자도 있으므로 모든 보상을 오류 없는 규칙 검증으로 분류하지 않는다.

논문은 Android-in-the-Wild 설정에서 정적 인간 시범 SFT 17.7%와 DigiRL 67.2%를 보고한다. 별도 앱·에뮬레이터·초기 상태와 평가자의 조건을 함께 기록한다. 다른 웹 벤치마크 점수와 같은 열에 합치지 않는다.

## 실행과 학습에서 기록하기

| 항목 | 예시 |
|------|------|
| 환경 | 사이트·앱 버전, 계정 초기 상태 |
| 관측 | DOM·접근성 트리·스크린샷 |
| 행동 | 클릭·입력·좌표·도구 스키마 |
| 보상 | 규칙 검증·모델 판정·최종 상태 |
| 예산 | 턴 수·생성 토큰·시간 제한 |
| 분할 | 학습 사이트·과제와 평가 과제 |

후속 관측을 기다리는 동안 다른 환경을 실행할 수 있다. 정책 버전·도구 결과·실패 유형은 궤적에 저장한다. 환경 장애와 작업 실패를 구분하되, 실패를 임의로 평가 분모에서 제외하지 않는다.

파일·구매·메시지 등 외부 상태를 바꾸는 행동의 권한은 실행기가 집행한다. 학습 보상은 권한을 대신하지 않는다. 실험은 초기화 가능한 격리 환경에서 수행한다.
